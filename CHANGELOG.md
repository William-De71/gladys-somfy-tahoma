## [0.1.0] - 2026-11-18

### Added

- Somfy TaHoma, TaHoma Switch and Connexoon boxes through the local API of the Developer Mode or the Somfy cloud, local first with the cloud as fallback, transport badges and degraded state
- covers (roller shutters, blinds, screens, windows, pergolas, awnings, curtains, garage doors, gates) with state, position and slats; lights with intensity; plugs; temperature, light, humidity, opening, motion, smoke, water leak, battery, CO2, power and energy sensors
- the box found on the network by mDNS, states pushed by the event listener of the box
- configuration button that enables the local mode from the TaHoma account (Developer Mode and token)
- scene triggers: command failed, device stops or resumes answering, box lost or back
- scene actions: run a TaHoma scenario (replayed locally in local mode), send a command (My, open, close, stop, identify)
- dashboard widgets: one cover, the box and its covers, the TaHoma scenarios
- documentation and texts in English, French, German and Spanish
